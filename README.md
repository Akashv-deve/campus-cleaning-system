## 🏗️ Tech Stack
* **Frontend:** Flutter (Dart)
* **Backend:** Spring Boot (Java, Maven)
* **Database:** MongoDB Atlas
* **Deployment:** Render (with automated 14-minute cron-job ping to prevent server cold-starts)

## ⚡ Core Features
* **Real-Time Role Assignment:** Dynamic allocation of rooms to sweepers and invigilators.
* **State Management:** Live status tracking (Pending, Cleaned, Verified).
* **Algorithmic Safeguards:** Custom duplicate room-blocking engine to prevent overlapping assignments.
* **Automated Reporting:** PDF report generation for daily campus cleaning logs.

## 🚀 Future Roadmap
* **Targeted Push Notifications:** Implementing Firebase Cloud Messaging (FCM) via topic subscriptions (e.g., `sweeper_ramesh`) to eliminate complex token-based user databases.
